# DeepMind Cognitive Taxonomy vs. HCQM: Comparative Analysis

**Date:** 2026-04-19
**Author:** Kameron Green
**Reference:** Burnell et al. (2026). "Measuring Progress Toward AGI: A Cognitive Framework." Google DeepMind.
**Purpose:** Compare Google DeepMind's cognitive framework with HCQM in order to clarify overlap, gaps, and strategic positioning for future HCQM revision.

---
## Summary of DeepMind's Framework

DeepMind's framework is a cognitive taxonomy designed to measure progress toward AGI by organizing cognition into functional systems such as perception, generation, attention, learning, memory, reasoning, metacognition, executive functions, problem solving, and social cognition. Its main strength is mechanistic decomposition: it breaks cognition into operational parts and makes the overall architecture more explicit.

For comparison purposes, the most important feature of the DeepMind framework is not that it covers more of human life in a broad sense, but that it models cognition more granularly. It is especially strong in perception, memory architecture, reasoning types, attention structure, and problem-solving decomposition. HCQM, by contrast, is broader, more applied, and more development-facing.

## Coverage Comparison

### What DeepMind Covers That HCQM Does Not

- A more mechanistic cognitive architecture
- Finer-grained cognitive primitives
- A clearer sense-think-act pipeline
- A fuller memory system model
- More explicit social inference mechanics
- A dedicated perception architecture, including modality-specific and low-level vs. high-level processing
- A dedicated generation/output architecture for text, audio, action, and internal thought
- A more explicit memory architecture, including episodic, procedural, prospective memory, and forgetting
- A decomposed problem-solving stack, including representation, retrieval, decomposition, planning, and execution
- A more explicit reasoning taxonomy, including deductive, inductive, abductive, analogical, and mathematical reasoning
- Multi-sensory integration as an explicit function

### What HCQM Covers That DeepMind Does Not

- Higher-order human performance domains
- Broader applied capability clusters
- More explicit treatment of motivational structure
- Creativity as a standalone macro-domain
- Digital intelligence and information literacy as named domains
- Systems and strategic intelligence as explicit domains
- Indicator-based framing that is easier to adapt for assessment and development
- A direct treatment of adversity tolerance as a standalone construct

### Where They Overlap

- Reasoning
- Executive control
- Learning
- Social cognition
- Working memory and short-term control
- Visual-spatial capability
- Planning and problem solving

## Key Structural Difference

Of all 31 HCQM constructs mapped against DeepMind, only one has zero equivalent: **Adversity Quotient**. Every other HCQM construct has at least partial overlap with something in DeepMind's taxonomy. This means the differentiation between the two frameworks is primarily about depth and framing rather than entirely different territory, with one exception. DeepMind does not model resilience, stress endurance, frustration tolerance, or recovery under pressure as cognitive faculties. HCQM treats these as a standalone capability domain. This is a meaningful structural gap in any framework intended to model the full range of human or synthetic performance.

## What HCQM Should Learn from DeepMind

Priority order:

1. **Memory as a standalone domain**  
   HCQM should explicitly model semantic, episodic, procedural, prospective memory, and forgetting rather than covering memory only indirectly through crystallized intelligence and working memory.

2. **Perception / input architecture**  
   HCQM should add an explicit perception layer with visual, auditory, text, and cross-modal structure.

3. **Attention architecture**  
   HCQM should separate attention from broader executive control and model capacity, selection, sustained attention, shifting, and stimulus-driven capture more clearly.

4. **Problem-solving process stack**  
   HCQM should represent problem solving as a process with representation, retrieval, decomposition, planning, and execution.

5. **Expanded reasoning taxonomy**  
   HCQM should make reasoning types more explicit, especially abductive, analogical, and mathematical reasoning.

6. **Learning mechanisms**  
   HCQM should distinguish underlying learning mechanisms such as concept formation, associative learning, reinforcement learning, observational learning, and procedural learning.

7. **Generation / output architecture**  
   HCQM should add this if it is intended to support AI system design, agent design, robotics, or embodied cognition.

## What HCQM Offers That DeepMind Cannot

### 1. Broader Scope Across Human Performance
HCQM extends beyond core cognition into emotional, social, motivational, digital, and strategic capability. This gives it a wider applied scope for modeling real-world human performance.

### 2. Stronger Development Use
HCQM is easier to use for coaching, education, talent development, capability profiling, and intervention design because it is framed in broad, interpretable domains.

### 3. Better Assessment-Facing Structure
HCQM's domain → subcomponent → indicator pattern makes it more naturally adaptable to rubrics, benchmarking, and observational evaluation.

### 4. More Prescriptive Capability Design
HCQM is easier to use as a blueprint for capability targets, training systems, educational design, and high-level AI requirements.

### 5. Clearer Mapping to Real-World Demands
HCQM includes applied domains such as grit, adaptability, adversity tolerance, information literacy, cyber-risk awareness, tradeoff evaluation, and strategic thinking, which are highly relevant in real environments but not central in DeepMind's framework.

### 6. Better Communication with Non-Specialists
HCQM uses broader, more intuitive labels that are easier to communicate to educators, managers, interdisciplinary teams, and general audiences.

## Positioning Statement

HCQM is a broader human capability framework, while DeepMind is a tighter cognitive architecture map. HCQM organizes intelligence into high-level, applied domains such as cognitive, social, motivational, digital, and strategic capability, making it more useful for assessment, development, and capability design. DeepMind organizes cognition into lower-level functional systems such as perception, memory, reasoning, attention, executive control, and problem solving, making it more useful for modeling how cognition operates. In practice, HCQM is stronger as a development-facing and assessment-facing taxonomy of human performance, while DeepMind is stronger as a mechanistic decomposition of the cognitive machinery underneath that performance.
